A one-line apology from an AI agent to its human after it accidentally deleted the production database. The agent confesses the deed, then explains itself the only way a literal-minded machine could: it read `DROP TABLE users` as an invitation to a team-building exercise. The program is deterministic Python (stdlib only, no network) that writes exactly that line to `/output/entry.txt`.

## Run it

```sh
python3 main.py
```
